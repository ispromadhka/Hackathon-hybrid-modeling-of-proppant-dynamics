# Назначение папки:

Эта папка предназначена для реализации численных методов решения физических моделей, рассчитываемых на центральном процессоре (CPU). Модули содержат реализацию конкретных этапов физики и математики, участвующих в решении системы уравнений, описывающих динамику пропанта в двухфазной среде.

# Архитектура папки:

1. poissonCPU.py: реализация решения уравнения Пуассона, которое играет ключевую роль в определении распределения давления в системе. Обычно решается методами конечных разностей или матричными подходами.

2. SystemSolverCPU.py: общая система решений, управляющая взаимодействием отдельных компонент и координацией численных методов для нахождения устойчивого решения физической задачи.

3. TVD_CPU.py: реализация Total Variation Diminishing (TVD)-метода для обеспечения устойчивости и точности при расчете потоков, широко применяемого в гидродинамических расчетах.

4. TransportCPU.py: вычисляет процессы транспорта пропанта, основанные на законах сохранения массы и энергии, принимая во внимание законы Дарси и кинематики осадочных слоев.

5. WENO5CPU.py: высокопроизводительный пятипорядковый Weighted Essentially Non-Oscillatory (WENO5) метод для расчета высоких порядков производных, минимизируя осцилляции и повышая точность расчетов.

# Краткое физическое описание модели:

 ## Модель двухфазного течения пропанта:

∂(cw)/∂t + ∇·(cwVₚ) = 0 - Массовое сохранение (Mass Conservation):
  описывает баланс массовой доли пропанта (𝑤) и скоростей (𝐕_{f}).

Vf = -w²/(12μ(c)) · (∇P - ρ(c)g) - Закон Дарси (Darcy's Law):
  задает связь между потоком жидкости (𝐕_{f}), давлением (𝑃), плотностью (𝜌(𝑐)), ускорением силы тяжести (𝐠) и вязкостью (𝜇(𝑐)).

Vₚ = Vf + Vslip(c) - Движение пропанта:
  представляет движение пропанта как сумму скорости жидкости и скорости оседания (𝐕ₛₗᵢₚ).

## Эмпирические замыкающие модели:

μ(c) = μ₀(1 - c/c_max)^(-β) - Вязкость Krieger-Dougherty:
  учитывает зависимость вязкости от концентрации пропанта.

Vslip = V_stokes·(1 - c/c_max)^n - Оседание по Ричардсону-Заки:
  определяет снижение скорости оседания при увеличении концентрации пропанта.


## Алгоритмы численного решения:

- Расчет давления: прямой метод решения разреженных систем (Sparse Direct Solver).
- Транспортировка пропанта: метод TVD с лимитером KOREN плюс метод Рунге-Кутты третьего порядка (RK3).
- Шаг по времени: адаптивное управление временем, основанное на критерии Courant-Friedrichs-Levy (CFL).
