# Назначение папки
Папка src/model предназначена для хранения модели машинного обучения, используемого в проекте

## Описание архитектуры FNO 
Используется продвинутая версия классической модели FNO (Fourier Neural Operator), специально адаптированная для модерилования движения проппанта:
1. Multi-scale spectral convolutions: Используются свёртки на разных масштабах частоты, что позволяет учитывать широкий диапазон частотных характеристик сигнала, делая модель более универсальной и точной.

2. U-Net style encoder-decoder with skip connections: Модель построена по принципу U-Net, что означает наличие энкодера и декодера с пропускаемыми соединениями (skip connections). Это улучшает передачу градиентов и повышает качество реконструкции деталей.

3. Residual learning: Применяется остаточное обучение, которое облегчает распространение градиентов назад и предотвращает проблему исчезновения градиентов, позволяя строить глубокие сети.

4. Spectral attention: Механизм внимания применяется в спектральном домене, что позволяет адаптивно выбирать важные частоты и подавлять менее значимые, увеличивая общую производительность модели.

5. High-Frequency Scaling (HFS): Специальная техника масштабирования высоких частот, позволяющая минимизировать смещение спектра, вызванное стандартными методами обучения.

6. Boundary-aware processing: Обработка граничных условий таким образом, чтобы обеспечить сохранение массы, что критично для точности модели в задаче транспортировки проппанта.
